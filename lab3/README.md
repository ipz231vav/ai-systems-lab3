# Лабораторна 3 — Токенізація та трансформери

- `transformers_demo.ipynb` — демонстраційні експерименти.
- `transformers_task.ipynb` — завдання 0–6, NewsLens.
- `models/`, `runs/`, `results.csv`, `tokenizer.json` — оригінальні артефакти навчання.

Запуск: відкрийте ноутбук у Jupyter або Colab та виконайте Run All. Потрібен інтернет для встановлення залежностей і завантаження моделей, рекомендовано GPU Tesla T4 або потужніший, достатньо диска (десятки ГБ). Google Drive не потрібен. У локальному Jupyter NewsLens відкривається на localhost, у Colab — за тимчасовим публічним посиланням.

Збережені результати — з початкових запусків. Повний повторний Run All після редагування не проводився; перевірено структуру ipynb та синтаксис Python. При повторному навчанні файли моделей і CSV можуть бути перезаписані.
